How Do Engineers Respond to City Comments?

Responding to city plan check comments requires a clear, point-by-point reply and revised documents. Here's how engineers resolve comments and keep permits moving.

The Short Answer

Engineers respond to city plan check comments by addressing each comment individually — either revising the drawings and calculations to correct the issue or providing a written clarification with code justification when the design is already compliant. The response is submitted as a formal comment-response letter alongside the revised, re-stamped documents, so the plan reviewer can see exactly how every item was resolved. A disciplined, point-by-point response is the fastest path to permit approval and the best way to avoid additional review cycles.

The Anatomy of a Good Response

Address Every Comment

Reviewers expect a response to each numbered comment, in order. Skipping a comment — even one the design team believes is minor or mistaken — almost always triggers another review cycle. We reproduce each comment and respond directly beneath it.

Correct or Clarify

Some comments require a design change: revise a member, add a detail, update a calculation. Others are requests for information where the design is already correct — in those cases we clarify, cite the applicable code section, and point the reviewer to where the requirement is satisfied in the set.

Show the Revisions

Revised documents should make changes easy to find — clouded revisions, revision deltas, and updated calculations. When the reviewer can quickly locate each change, the re-review moves faster.

When You Disagree With a Comment

Reviewers occasionally issue comments based on a misreading of the drawings or a code interpretation the design team disagrees with. The professional approach is to respond respectfully with a technical justification — the governing code provision, the analysis basis, and the reasoning. Most such disagreements are resolved through a clear written explanation. When needed, a phone call or meeting with the reviewer can settle interpretation questions efficiently.

Coordinating Across Disciplines

A single comment can touch multiple disciplines — a structural change that affects mechanical routing, for example. As a multi-discipline firm, we coordinate comment responses internally so the revised set stays consistent and a fix in one discipline doesn't create a conflict in another. This coordination is one of the biggest advantages of keeping the engineering team under one roof.

When It Applies

Comment responses apply any time a project goes through plan check and the reviewer returns correction items — which is the norm rather than the exception. Even well-prepared submittals typically receive some comments. The goal is to resolve them in as few cycles as possible.

Frequently Asked Questions

How many rounds of comments are normal?

Most projects resolve in one to three cycles. Complex projects or stricter jurisdictions may take more. A complete initial submittal reduces the number.

Do revised drawings need to be re-stamped?

Yes. When engineering documents are revised, the engineer of record re-seals the updated set, since the seal must reflect the current design.

Can you respond to comments on a project another firm designed?

We can, but only after reviewing the design substantively so we can take responsibility for it — the same responsible-charge standard applies as with any sealed work.
