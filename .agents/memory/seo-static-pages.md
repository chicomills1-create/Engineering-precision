---
name: Static SEO page generation
description: How the programmatic SEO pages for apex-grid work and dev-server gotchas
---
- 251 static pages (hub + 50 states + 200 state×service) are generated by `pnpm --filter @workspace/apex-grid run seo:generate` into `public/locations/`; it also rebuilds sitemap.xml. Data lives in `seo/states/*.ts` (StateData interface).
- **Why static:** the site is a Vite SPA (invisible to Googlebot); static HTML in public/ ships in the build output and is crawlable.
- **Gotcha:** Vite dev caches the public-dir file list — after regenerating pages, restart the web workflow or deep paths serve the SPA fallback. A dev-only vite plugin (`staticDirIndex`) rewrites `/locations/**/` directory URLs to index.html.
- **How to apply:** after editing state data, run seo:generate, restart web workflow, and republish for production.
